나란히 걸어봄 개인정보 처리방침

시행일: 2026년 9월 15일

나란히 걸어봄은 회원가입을 요구하지 않습니다. 생활 조건, 7일 돌봄·회고 기록과 알림 설정 등 핵심 앱 데이터는 기본적으로 이용자의 기기에 저장되며, App Store 1.0 공개 버전에서는 광고·행동 추적·사용자 분석을 운영하지 않습니다. 고객지원 이메일을 보내는 경우에는 문의 처리에 필요한 정보만 처리합니다.

이응랩스(개인 개발자, 이하 “운영자”)는 「개인정보 보호법」 등 관련 법령에 따라 이용자의 개인정보를 보호하고 관련 문의를 처리하기 위해 다음과 같이 개인정보 처리방침을 공개합니다.

1. 개인정보의 처리 목적·항목·보유기간

앱 기능 데이터 주거 환경, 평일 외출 시간 등 사용자가 선택한 생활 조건, 연습 프로필, 돌봄·회고 기록, 메모, 알림 설정과 리포트 생성을 위한 상태는 이용자 기기에 저장됩니다. 운영자는 App Store 1.0 공개 버전에서 이 핵심 시뮬레이션 데이터를 자체 서버로 수집하지 않습니다. 이용자는 새 시뮬레이션 시작 또는 앱 삭제를 통해 기기 내 데이터를 삭제할 수 있습니다.
앱 내 의견 기록 App Store 1.0 공개 버전에서 서버 전송 경로가 설정되지 않은 앱 내 의견은 기기에만 보관됩니다. 운영 서버로 의견을 전송하는 기능을 향후 활성화하는 경우, 실제 전송 항목·목적·보유기간과 삭제 방법을 반영해 이 처리방침과 App Store 개인정보 표시를 먼저 갱신합니다.
고객지원 이메일 문의 답변과 문제 해결을 위해 발신 이메일 주소, 이용자가 이메일에 기재한 이름·문의 내용·첨부파일을 처리할 수 있습니다. 문의 처리 완료 후 30일 이내 삭제하는 것을 원칙으로 하며, 관계 법령에 따라 보존할 필요가 있는 경우 해당 기간 동안만 보관합니다.

2. 알림 권한

돌봄 알림은 사용자가 선택한 경우에만 iOS 알림 권한을 요청합니다. App Store 1.0 공개 버전은 원격 푸시 서버를 이용해 개인별 푸시 토큰을 수집하지 않으며, 앱의 돌봄 일정에 맞춘 기기 로컬 알림을 사용합니다. 알림 권한은 iOS 설정에서 언제든 변경할 수 있습니다.

3. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 판매하거나 임의로 제공하지 않습니다. 법령에 특별한 규정이 있거나 이용자가 별도로 요청·동의한 경우에는 예외로 합니다.

4. 외부 서비스 이용과 국외 처리

고객지원 이메일의 송수신과 보관을 위해 Gmail을 이용합니다. 이용자가 고객지원 이메일을 보내면 다음 정보가 Google의 글로벌 인프라에서 처리될 수 있습니다.

  • 처리 제공자: Google LLC
  • 처리 항목: 발신 이메일 주소, 이메일에 포함된 이름·문의 내용·첨부파일
  • 처리 시기와 방법: 이메일 발송 시 암호화된 통신망을 통한 전송
  • 이용 목적: 고객지원 이메일 송수신·저장과 보안
  • 운영자 보유기간: 문의 처리 완료 후 30일 이내 삭제를 원칙으로 함

자세한 Google의 처리 방식은 Google 개인정보처리방침에서 확인할 수 있습니다.

이 개인정보 처리방침과 고객지원 페이지는 GitHub Pages로 공개됩니다. 페이지 방문 시 GitHub, Inc.가 페이지 제공과 보안을 위해 IP 주소, 브라우저·기기 정보, 접속 시각 및 요청 기록을 처리할 수 있습니다. 운영자는 별도의 방문자 분석 스크립트를 설치하지 않습니다. 자세한 내용은 GitHub 개인정보처리방침을 따릅니다.

5. 개인정보의 파기

  • 기기 내부 앱 데이터: 사용자가 앱 기능 또는 iOS 앱 삭제 기능을 통해 직접 삭제할 수 있습니다.
  • 고객지원 이메일: 보유기간 종료 후 메일함과 휴지통에서 삭제합니다.
  • 법령에 따라 별도 보관이 필요한 경우에는 해당 정보만 분리해 필요한 기간 동안 보관합니다.

6. 이용자의 권리와 행사 방법

이용자는 고객지원 이메일을 통해 고객지원 과정에서 처리된 개인정보에 대한 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다. 기기에만 저장되는 앱 기록은 운영자가 원격으로 열람하거나 복구할 수 없으며 이용자가 직접 삭제할 수 있습니다.

7. 개인정보의 안전성 확보조치

운영자는 핵심 시뮬레이션 데이터를 자체 서버에 저장하지 않는 것을 원칙으로 하며, 고객지원 메일 계정의 접근권한과 인증수단을 관리하고 처리 목적이 끝난 문의를 정기적으로 삭제합니다.

8. 자동 수집 장치와 추적

App Store 1.0 공개 버전의 앱에는 운영자가 사용하는 광고 SDK, 사용자 행동 분석 SDK 또는 제3자 추적 도구를 두지 않습니다. 공개 웹페이지는 GitHub Pages 제공에 필요한 기술적 요청 정보를 처리할 수 있으며 그 범위는 제4항과 같습니다.

회원가입, 서버 저장, 광고, 분석, 원격 푸시 또는 서버 기반 의견 수집 등 개인정보 처리 방식이 변경되는 경우 실제 기능을 공개하기 전에 이 방침과 App Store 개인정보 표시를 실제 처리 내용에 맞게 갱신합니다.

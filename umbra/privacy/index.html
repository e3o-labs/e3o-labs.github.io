Umbra 개인정보 처리 안내

작성 기준: 2026년 10월 29일 · 현재 journal 구현 기준

이 안내는 Umbra의 현재 데이터 처리 범위를 설명합니다. 개인정보 관련 문의는 redsunjin@gmail.com으로 보내실 수 있습니다. 문의에는 필요한 정보만 포함하고 개인 기록이나 민감정보는 보내지 마세요.

1. 기기에 보관되는 정보

현재 journal은 별도 회원가입 없이 사용할 수 있으며, 다음 정보를 사용하는 기기의 브라우저 또는 앱 웹뷰 저장소에 보관합니다.

항목이용 목적
글, 생성·수정·삭제 시각, 작성 중 초안기록 저장·검색·수정·휴지통·초안 복원
지역명, 좌표, 시간대, 빛 정보현재 빛 계산과 기록 당시 공간 재현
선택한 오브제, 등록 사진과 이름공간 표현·사진 보관함·백업

현재 journal에는 기록과 사진을 운영자의 계정 서버로 동기화하는 기능이 없습니다. 브라우저 사이트 데이터 삭제, 앱 삭제나 저장 환경 변경으로 자료가 사라질 수 있으므로 필요한 기록은 별도 백업해 주세요.

2. 현재 위치

‘현재 위치’를 선택한 경우에만 기기의 위치 권한을 요청합니다. 얻은 좌표는 사용자가 지역을 적용하면 지역 설정과 빛 계산에 사용되며, 기록 당시 공간 정보에 포함될 수 있습니다. 위치를 허용하지 않아도 도시를 선택하거나 좌표와 시간대를 직접 입력할 수 있습니다. 현재 journal 코드에는 좌표를 운영자 서버로 전송하는 기능이 없습니다.

선택 기능: 계절·날씨 표지

계절 색감과 직접 선택한 날씨 분위기는 기기 안에서 처리합니다. 실제 날씨 예보 연동은 기본적으로 꺼져 있으며, 사용자가 별도로 켜면 선택 지역의 좌표를 소수점 첫째 자리(약 0.1도)로 반올림하여 MET Norway에 요청합니다. 기상 제공사는 요청 좌표와 접속 IP를 로그로 처리합니다. 기록 본문, 사진, 이름이나 앱 식별자는 이 요청에 포함하지 않습니다. 예보 연동을 위해 추가로 현재 위치 권한을 요청하지 않습니다.

기상 자료는 관측 사실이 아닌 1시간 예보입니다. 앱은 자료 시각·수신 시각·출처와 저장 당시 표지 상태를 기기에 보관하며 기록 백업에도 포함합니다. 전용 예보 캐시는 최대 네 지역으로 제한하고 연동을 끄면 삭제합니다. 이미 기록에 저장된 당시 예보는 기록·백업의 일부로 유지됩니다. 연동을 꺼도 이후 기상 요청은 중단되며 기록 작성은 계속할 수 있습니다.

MET Norway는 서비스 요청 로그를 오슬로에서 처리한다고 안내합니다. 제공사의 정확한 보관 기간은 이 앱에서 정하지 않습니다. 자세한 사항은 MET Norway 이용·로그 안내를 참고하세요. 예보 자료 출처는 MET Norway이며 CC BY 4.0에 따라 사용합니다.

3. 개인 사진

사용자가 직접 선택해 등록한 사진을 오브제로 사용합니다. 현재 journal은 사진을 축소해 로컬에 보관하며 기록 및 백업에 포함할 수 있습니다. 촬영·사진 선택에 사용하는 기기 권한은 운영체제 설정에서 관리할 수 있습니다. 기록·휴지통·편집 초안·현재 공간에서 사용하는 사진은 삭제가 제한됩니다.

4. 백업과 외부 공유

사용자가 내보내는 백업에는 기록과 개인 사진 등이 포함될 수 있습니다. 백업은 사용자가 선택한 저장 위치나 공유 대상으로 전달됩니다. 현재 journal은 백업 파일을 운영자 서버에 자동 업로드하지 않습니다. 외부 저장·공유 서비스를 선택하면 해당 서비스의 정책이 적용됩니다. 파일을 전달하기 전에 포함된 정보를 확인해 주세요.

5. 기록 보관과 삭제

기록을 휴지통으로 옮겨도 복원할 수 있도록 로컬에 남습니다. 휴지통에서 영구 삭제한 기록은 앱의 기록 목록에서 제거되며 앱에서 되돌릴 수 없습니다. 사진 보관함은 기록과 별도로 관리됩니다.

이미 내보낸 백업 파일은 앱 안에서 삭제해도 자동으로 지워지지 않습니다. 예전 백업을 가져오면 그 안에 있던 기록과 사진이 다시 추가될 수 있습니다. 필요하지 않은 백업은 보관한 위치에서 직접 삭제해 주세요. 브라우저의 사이트 데이터 삭제 또는 운영체제의 앱 데이터·앱 삭제 기능을 이용할 때에는 먼저 필요한 자료를 백업해 주세요.

6. 소개 페이지와 외부 서비스

이 소개·지원 페이지에는 운영자의 방문자 분석 스크립트나 광고 추적 도구를 추가하지 않았습니다. 현재 확인한 journal에도 광고·행동 분석 기능은 포함되어 있지 않습니다.

이 페이지가 GitHub Pages에서 제공될 때에는 페이지 전달과 보안을 위한 접속 정보가 호스팅 제공자를 통해 처리될 수 있습니다. 자세한 내용은 GitHub 개인정보 보호 안내를 참고하세요.

이메일로 문의하면 발신 이메일 주소, 문의 본문과 첨부파일이 문의 대응을 위해 운영자와 이메일 제공자를 통해 처리됩니다. 공개 저장소나 이메일에 문제 확인에 불필요한 개인 글·사진·정확한 위치·백업 원본을 보내지 마세요.

문의 메일 작성

앱 버전, iPhone 모델·iOS 버전, 문제가 생긴 순서와 오류 문구를 적어 주세요. 화면을 첨부한다면 기록과 개인정보를 가려 주세요. 전체 JSON 파일, 비밀번호나 민감정보는 보내지 마세요. 답변에 필요한 내용을 확인해 안내합니다. 문의 메일과 첨부파일은 처리 완료 후 30일 이내 운영자 메일함에서 삭제합니다.

자주 묻는 질문

기록을 다른 기기로 옮기려면?

보관함의 백업 안내 또는 설정에서 ‘기록 내보내기’로 JSON 파일을 보관하고, 새 기기에서 ‘기록 가져오기’를 사용하세요. 가져오기는 파일 미리보기와 확인 내용을 읽은 뒤 진행하고, 먼저 현재 기록도 내보내 보관하세요. iOS 공유 화면에서 선택한 저장 위치에 파일이 실제로 저장되었는지 확인하세요.

저장 오류나 빈 화면이 보이면?

앱을 삭제하거나 데이터를 덮어쓰기 전에 멈추고, 내보내기가 가능하다면 원본 파일을 먼저 보관하세요. 앱이 제공하는 직전 안전 백업 복구 안내를 확인하세요. 직전 백업은 모든 과거 버전을 보관하는 기능이 아니며, 앱 삭제 후 복원을 보장하지 않습니다. 운영자에게 오류 문구와 발생 순서를 알려 주세요.

기록을 모두 삭제하려면?

먼저 필요한 기록을 내보낸 뒤 iOS 설정 → 일반 → iPhone 저장 공간 → Lucky → ‘앱 삭제’를 사용하세요. ‘앱 정리하기’는 데이터가 남을 수 있습니다. 내보낸 파일과 공유 사본, 기기 백업은 별도로 삭제해야 합니다. 운영자는 기기 기록을 원격으로 삭제하거나 복구할 수 없습니다.

자동 동기화나 AI 예측을 제공하나요?

현재 버전은 기기 안에서 기록하고 규칙 기반 안내를 제공합니다. 자체 클라우드 동기화나 원격 AI 분석·미래 예측을 제공하지 않습니다. iCloud 등 기기 백업은 Apple과 사용자 설정에 따릅니다.

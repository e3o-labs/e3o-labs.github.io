나란히 걸어봄 개인정보 처리방침

시행일: 2026년 10월 22일

나란히 걸어봄은 회원가입을 요구하지 않습니다. 생활 조건, 7일 돌봄·회고 기록과 알림 설정 등 핵심 앱 데이터는 기본적으로 이용자의 기기에 저장되며, App Store 1.0 공개 버전에서는 광고·행동 추적·사용자 분석을 운영하지 않습니다. 앱에서 의견을 직접 제출하거나 고객지원 이메일을 보내는 경우에만 문의 처리에 필요한 정보를 서버에서 처리합니다.

운영자는 「개인정보 보호법」 등 관련 법령에 따라 이용자의 개인정보를 보호하고 관련 문의를 처리하기 위해 다음과 같이 개인정보 처리방침을 공개합니다.

1. 개인정보의 처리 목적·항목·보유기간

앱 기능 데이터 주거 환경, 평일 외출 시간 등 사용자가 선택한 생활 조건, 연습 프로필, 돌봄·회고 기록, 메모, 알림 설정과 리포트 생성을 위한 상태는 이용자 기기에 저장됩니다. 운영자는 App Store 1.0 공개 버전에서 이 핵심 시뮬레이션 데이터를 자체 서버로 수집하지 않습니다. 이용자는 새 시뮬레이션 시작 또는 앱 삭제를 통해 기기 내 데이터를 삭제할 수 있습니다.
앱 내 의견 기록 이용자가 ‘의견 보내기’를 선택하면 의견 내용·분류, 서비스 및 접수 식별자, 접수 시각, 앱 버전·빌드, 운영체제·플랫폼, 이용 화면 식별자를 서비스 개선과 오류 대응을 위해 Cloudflare Workers·D1 공통 수집기에 전송·저장합니다. 생활 조건과 돌봄·회고 기록은 자동으로 첨부하지 않습니다. 의견 원문과 별도 동의해 입력한 연락처가 있는 경우 해당 연락처는 접수 후 30일이 지나면 자동 삭제합니다. 현재 앱에는 답변용 연락처 입력과 사진·첨부파일 업로드가 없습니다. 의견을 모델 학습에 사용하지 않습니다. 제출은 선택 사항이며 제출하지 않아도 기본 서비스를 이용할 수 있습니다. 전송을 확인하지 못한 의견은 기기에 보관하고 재시도합니다.
고객지원 이메일 문의 답변과 문제 해결을 위해 발신 이메일 주소, 이용자가 이메일에 기재한 이름·문의 내용·첨부파일을 처리할 수 있습니다. 문의 처리 완료 후 30일 이내 삭제하는 것을 원칙으로 하며, 관계 법령에 따라 보존할 필요가 있는 경우 해당 기간 동안만 보관합니다.

2. 알림 권한

돌봄 알림은 사용자가 선택한 경우에만 iOS 알림 권한을 요청합니다. App Store 1.0 공개 버전은 원격 푸시 서버를 이용해 개인별 푸시 토큰을 수집하지 않으며, 앱의 돌봄 일정에 맞춘 기기 로컬 알림을 사용합니다. 알림 권한은 iOS 설정에서 언제든 변경할 수 있습니다.

3. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 판매하거나 임의로 제공하지 않습니다. 법령에 특별한 규정이 있거나 이용자가 별도로 요청·동의한 경우에는 예외로 합니다.

4. 외부 서비스 이용과 국외 처리

앱 내 의견 접수·원문 보관·삭제 요청 처리를 위해 Cloudflare Workers·D1을 이용합니다. 위 제1항의 의견 및 기술 정보는 제출 시 암호화된 통신망으로 전달되며 Cloudflare의 해외 인프라에서 처리될 수 있습니다. 운영자는 관리자 인증 후 원문을 조회하고 삭제 요청을 처리합니다. 보안과 요청 제한을 위해 접속 정보가 기술적으로 처리될 수 있으나 광고나 행동 추적에 사용하지 않습니다.

매일 오전 9시(한국 시간), 새 의견이 있는 경우에만 Google Apps Script·MailApp으로 관리자에게 서비스·분류·플랫폼별 건수 요약을 보냅니다. 의견 원문과 연락처는 이 요약 메일에 넣지 않습니다. 공통 수집기의 처리 경로와 삭제 문의는 공통 의견 접수 개인정보 안내에서도 확인할 수 있습니다.

고객지원 이메일의 송수신과 보관을 위해 Gmail을 이용합니다. 이용자가 고객지원 이메일을 보내면 다음 정보가 Google의 글로벌 인프라에서 처리될 수 있습니다.

  • 처리 제공자: Google LLC
  • 처리 항목: 발신 이메일 주소, 이메일에 포함된 이름·문의 내용·첨부파일
  • 처리 시기와 방법: 이메일 발송 시 암호화된 통신망을 통한 전송
  • 이용 목적: 고객지원 이메일 송수신·저장과 보안
  • 운영자 보유기간: 문의 처리 완료 후 30일 이내 삭제를 원칙으로 함

자세한 Google의 처리 방식은 Google 개인정보처리방침에서 확인할 수 있습니다.

이 개인정보 처리방침과 고객지원 페이지는 GitHub Pages로 공개됩니다. 페이지 방문 시 GitHub, Inc.가 페이지 제공과 보안을 위해 IP 주소, 브라우저·기기 정보, 접속 시각 및 요청 기록을 처리할 수 있습니다. 운영자는 별도의 방문자 분석 스크립트를 설치하지 않습니다. 자세한 내용은 GitHub 개인정보처리방침을 따릅니다.

5. 개인정보의 파기

  • 기기 내부 앱 데이터: 사용자가 앱 기능 또는 iOS 앱 삭제 기능을 통해 직접 삭제할 수 있습니다.
  • 앱 내 의견: 원문과 연락처는 접수 후 30일이 지나면 매일 자동 정리하며, 관리자 조회 전에도 기한을 확인합니다. 중복 접수와 복구 시 원문 부활을 방지하기 위한 접수 식별자·원문 해시·삭제 상태·처리 기록 및 분류별 집계는 유지합니다. 백업은 제공업체의 보관 주기에 따라 만료되며 복구 시 삭제 기록과 보관 기한을 먼저 적용합니다.
  • 고객지원 이메일: 보유기간 종료 후 메일함과 휴지통에서 삭제합니다.
  • 법령에 따라 별도 보관이 필요한 경우에는 해당 정보만 분리해 필요한 기간 동안 보관합니다.

6. 이용자의 권리와 행사 방법

이용자는 앱의 ‘접수 내역과 삭제 요청’에서 기기에 저장된 접수증으로 서버 의견의 삭제를 요청하거나, 고객지원 이메일을 통해 열람·정정·삭제·처리정지를 요청할 수 있습니다. 앱의 로컬 기록 초기화나 앱 삭제만으로 이미 서버에 접수된 의견이 삭제되지는 않습니다. 기기에만 저장되는 앱 기록은 운영자가 원격으로 열람하거나 복구할 수 없으며 이용자가 직접 삭제할 수 있습니다.

7. 개인정보의 안전성 확보조치

핵심 시뮬레이션 기록은 기기에 저장합니다. 서버 의견의 관리자 원문 조회는 인증된 관리자 세션 또는 서버 전용 인증으로 제한하며 관리자 비밀키를 앱이나 공개 웹 번들에 넣지 않습니다. 고객지원 계정의 접근권한과 인증수단을 관리하고 보관 기한이 끝난 원문을 정리합니다.

8. 자동 수집 장치와 추적

App Store 1.0 공개 버전의 앱에는 운영자가 사용하는 광고 SDK, 사용자 행동 분석 SDK 또는 제3자 추적 도구를 두지 않습니다. 공개 웹페이지는 GitHub Pages 제공에 필요한 기술적 요청 정보를 처리할 수 있으며 그 범위는 제4항과 같습니다.

10. 처리방침의 변경

회원가입, 서버 저장, 광고, 분석, 원격 푸시 또는 서버 기반 의견 수집 등 개인정보 처리 방식이 변경되는 경우 실제 기능을 공개하기 전에 이 방침과 App Store 개인정보 표시를 실제 처리 내용에 맞게 갱신합니다.

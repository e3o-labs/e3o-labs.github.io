이 안내는 앱의 현재 데이터 처리 범위를 설명합니다. 개인정보 관련 문의는 redsunjin@gmail.com으로 보낼 수 있습니다. 필요한 정보만 보내고 민감정보는 포함하지 마세요.

1. 기기에 저장되는 정보

TRIP119는 회원가입 없이 사용할 수 있으며 광고 추적 SDK를 사용하지 않습니다. 사용자가 입력한 여행 상황, 선택한 조건과 후보, AI 도움 메모, 온보딩 설정은 해당 iPhone의 앱 저장 공간에 보관됩니다. 사용자가 직접 저장한 JSON 백업 파일은 사용자가 고른 위치에 저장되며 TRIP119 서버로 업로드되지 않습니다.

저장된 여정은 여정 기록 화면에서 삭제할 수 있습니다. 앱을 삭제하면 앱 컨테이너에 남은 기록도 iOS의 앱 삭제 방식에 따라 제거됩니다.

2. 여행 후보 요청 때 처리되는 정보

공공 관광 후보를 찾을 때 앱은 다음 구조화된 값만 TRIP119 Runtime으로 전송합니다.

  • 시·도 및 시·군·구 코드
  • 관광 콘텐츠 분류
  • 짧은 도보, 실내, 휴식 등 제한된 조건 태그
  • 부산 권역에 한정된 제한된 상황 태그
  • 요청할 최대 후보 수

사용자가 입력한 원문, 이름, 연락처, 숙소명, 예약번호, 정밀 좌표, 계정·기기 식별자는 후보 요청에 포함되지 않습니다. 동일 조건의 응답 캐시는 안정적 제공을 위해 최대 15분 유지될 수 있으며 사용자 프로필과 연결하지 않습니다.

3. 현재 위치

현재 위치로 자동 선택을 사용한 경우에만 iOS 위치 권한을 요청합니다. 위치는 iPhone에서 대략적인 행정구역으로 변환하며, TRIP119 Runtime에는 정밀 좌표 대신 행정구역 코드만 보냅니다. 위치 권한을 거절해도 지역을 직접 선택할 수 있습니다.

4. 익명 개선 데이터

익명 개선 데이터 보내기는 기본값이 꺼져 있습니다. 사용자가 직접 켠 경우에만 행정구역 코드, 제한된 조건 태그, 표시·선택된 후보의 관광 분류, 표시 또는 선택 여부, 일 단위 날짜와 앱 버전을 통계 형태로 전송합니다. 원문, 장소명, 정밀 위치, 이름·연락처, 숙소·예약정보, 사용자·기기 식별자는 포함하지 않습니다.

이 데이터는 서비스 제안 품질의 평가·개선에만 사용하며 광고나 사용자 추적에는 사용하지 않습니다. 식별자를 수집하지 않으므로 특정 개인의 기록을 찾아 연결하거나 개별 삭제할 수 없습니다. 목적 달성 또는 서비스 종료 후 더 이상 필요하지 않으면 삭제합니다.

5. 외부 서비스와 기술 정보

사용자가 지도 또는 외부 AI 도움을 선택하면 Apple 지도, 네이버 지도, Google 지도, ChatGPT, Gemini, Claude 등의 공식 앱이나 웹사이트로 이동할 수 있습니다. 이때 처리되는 정보에는 각 서비스의 정책이 적용됩니다.

TRIP119 Runtime은 Cloudflare Workers와 D1에서 운영될 수 있습니다. 요청 전달, 보안, 장애 대응 과정에서 IP 주소 같은 기술 정보가 일시적으로 처리될 수 있으며, 이를 사용자 프로필이나 광고 식별자로 사용하지 않습니다.

6. 아동과 긴급 상황

앱은 계정, 생년월일 또는 아동의 개인정보를 요구하지 않습니다. TRIP119는 119 긴급신고·구조 서비스가 아닙니다. 생명이나 안전이 위급한 상황에서는 즉시 119 또는 현지 긴급기관에 연락해야 합니다.

# TRIP119 public site

이 디렉터리는 TRIP119의 공개 웹 결과물만 관리합니다.

- 제품 소개: `index.html`
- 지원: `support/`
- 개인정보 처리 안내: `privacy/`
- GitHub Pages: `https://e3o-labs.github.io/trip119/`
- 기존 지원 문서: `https://trip119-public-docs.pages.dev/support/`

운영 정책과 내부 작성 계획은 private 제품 저장소 `e3o-labs/trip119`에서 관리하며, 이 public 저장소에는 공개 결과물과 공개 경로 관계만 둡니다.

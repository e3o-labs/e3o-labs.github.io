# TRIP119 public site

이 디렉터리는 TRIP119 공개 사이트의 실제 배포 소스를 관리합니다.

Cloudflare Pages 프로젝트 `trip119-public-docs`가 이 디렉터리를 사이트 루트로 서비스하는 것을 기준으로 합니다.

- 제품 소개: `index.html` → `https://trip119-public-docs.pages.dev/`
- 지원: `support/index.html` → `https://trip119-public-docs.pages.dev/support/`
- 개인정보 처리 안내: `privacy/index.html` → `https://trip119-public-docs.pages.dev/privacy/`

`e3o-labs.github.io/trip119/`은 저장소 안의 소스 경로이며 운영 서비스 주소로 사용하지 않습니다.

운영 정책과 내부 작성 계획은 private 제품 저장소 `e3o-labs/trip119`에서 관리하고, 이 public 저장소에는 실제 공개 결과물과 최소한의 관계 인덱스만 둡니다.

# TRIP119 public site

이 디렉터리는 TRIP119 공개 웹페이지의 결과물을 관리합니다.

현재 운영 기준 주소는 GitHub Pages입니다.

- 제품 소개: `index.html` → `https://e3o-labs.github.io/trip119/`
- 지원: `support/index.html` → `https://e3o-labs.github.io/trip119/support/`
- 개인정보 처리 안내: `privacy/index.html` → `https://e3o-labs.github.io/trip119/privacy/`

`https://trip119-public-docs.pages.dev/` 배포는 생성 배경과 source 연결을 현재 Git 이력에서 확인하지 못한 보조/과거 배포로 취급합니다. 운영 주소로 승격하려면 source repository, branch, 배포 절차를 먼저 확인합니다.

운영 정책과 내부 작성 계획은 private 제품 저장소 `e3o-labs/trip119`에서 관리하고, 이 public 저장소에는 실제 공개 결과물과 최소한의 관계 인덱스만 둡니다.

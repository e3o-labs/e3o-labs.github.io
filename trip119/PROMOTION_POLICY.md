# TRIP119 홍보·지원 페이지 운영 정책

작성일: 2026-09-28

## 목적

이 문서는 TRIP119의 공개 소개 페이지와 지원 페이지를 운영할 때 지켜야 할 기준을 정한다.

홍보 페이지는 실제로 제공 중인 기능과 앞으로 준비하는 기능을 구분해서 보여준다. 개발 저장소의 계획보다 앞서서 기능을 약속하지 않고, 이미 배포된 기능을 오래된 상태로 남겨두지도 않는다.

## 기준 문서

홍보 내용은 `e3o-labs/trip119`의 현재 문서를 기준으로 확인한다.

우선순위는 다음과 같다.

1. `docs/status/current.md`
2. 현재 출고 대상 빌드 계획
3. `docs/plans/*product-evolution*.md` 등 후속 제품 계획
4. 제품·플랫폼별 별도 계획 문서

과거 문서나 실험 브랜치의 아이디어만으로 공개 페이지에 기능을 확정해서 적지 않는다.

## 공개 상태 표기

- **제공 중**: 실제 배포된 버전에서 사용할 수 있는 기능
- **다음 업데이트**: 다음 출고 범위로 확정된 기능
- **개발 중**: 구현이 시작된 기능
- **준비 중**: 제품 방향은 정해졌지만 아직 출시되지 않은 기능이나 플랫폼
- **검토 중**: 실험·조사 단계이며 구현 여부가 확정되지 않은 항목

내부 Build 번호, 브랜치명, PR 번호는 일반 홍보 문구에 넣지 않는다. 필요한 경우 저장소 문서에서만 관리한다.

## 문체

홍보 문구는 실제 서비스를 만드는 사람이 직접 설명하는 문체를 사용한다.

- 기능이 무엇을 하는지 사용 장면으로 설명한다.
- 과한 수식어와 추상적인 표현은 피한다.
- "혁신적인", "최적의", "완벽한", "스마트한 경험"처럼 근거 없는 표현은 쓰지 않는다.
- 짧은 문장과 평범한 한국어를 우선한다.
- 같은 문장 구조를 반복하지 않는다.
- 아직 없는 기능을 현재 기능처럼 쓰지 않는다.
- 기술 용어보다 사용자가 이해할 수 있는 표현을 우선한다.

예:

- 피함: "예상치 못한 상황에 유연하게 대응하는 최적의 여행 경험을 제공합니다."
- 사용: "비가 오거나 시간이 부족해졌을 때, 지금 갈 수 있는 곳을 다시 찾아봅니다."

## 제품 소개 범위

현재 iPhone을 주력 플랫폼으로 소개한다.

Android와 Web은 실제 출시 전까지 **준비 중**으로 표시한다. 구현 기술이나 출시일이 확정되지 않았다면 공개 페이지에서 특정 프레임워크, 일정, 기능 범위를 약속하지 않는다.

후속 기능은 TRIP119 저장소의 계획에 맞춰 다음과 같은 순서로 소개할 수 있다.

- 저장한 여행 기록과 현재 여행 정리
- 긴급 여행지 추천 UX 개선
- 방문 완료와 선택 후기
- Journey Graph
- 확인된 좌표 기반 지도
- 지도·변경이력·Journey Graph 연결
- 위치 검색, 이동시간, 우회 정도를 고려한 추천 개선

구현 순서가 바뀌면 저장소 문서를 먼저 갱신하고 홍보 페이지를 뒤따라 수정한다.

## 문의 운영

현재 문의 채널은 이메일을 유지한다.

- 현재: 이메일 문의 제공 + "문의폼 준비 중" 표시
- 문의폼 URL 확정 후: Google Forms 문의 버튼으로 전환
- 문의폼 전환이 확인되면 공개 페이지의 이메일 주소는 제거

폼에는 필요한 정보만 받도록 하고, 예약번호·정확한 위치 기록·비밀번호·결제 정보 등 민감정보를 보내지 않도록 안내한다.

문의폼 URL이 없는 상태에서 빈 링크나 임시 URL을 공개하지 않는다.

## 페이지 역할

### 소개 페이지

다음을 한 페이지에서 보여준다.

- TRIP119가 해결하려는 상황
- 지금 사용할 수 있는 기능
- 실제 앱 화면 또는 제품 이미지
- 다음 업데이트
- 이후 제품 방향
- iPhone / Android / Web 상태
- 지원 페이지 연결

### 지원 페이지

다음을 중심으로 유지한다.

- 문의 방법
- 문제 제보 시 필요한 정보
- 보내지 말아야 할 정보
- 개인정보 처리 안내
- 자주 확인할 내용

홍보 문구와 지원 절차가 섞여 지원 정보를 찾기 어려워지지 않게 한다.

## 업데이트 절차

기능이나 플랫폼 상태가 바뀔 때 다음 순서로 갱신한다.

1. TRIP119 저장소의 현재 상태와 계획을 확인한다.
2. 공개 상태를 `제공 중 / 다음 업데이트 / 개발 중 / 준비 중 / 검토 중` 중 하나로 판단한다.
3. 홍보 페이지 문구를 수정한다.
4. 지원·개인정보 문구에 영향이 있는지 확인한다.
5. 변경 내용을 커밋하고 공개 페이지를 확인한다.

홍보 페이지는 로드맵 자체가 아니라 제품의 현재 상태를 사람이 읽기 쉽게 보여주는 창구다.

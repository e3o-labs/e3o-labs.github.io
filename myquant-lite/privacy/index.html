1. 운영자와 적용 범위

운영자는 sunjin jo이며 개인정보 관련 문의는 redsunjin@gmail.com으로 보낼 수 있습니다. 이 안내는 MyQuant Lite의 현재 iPhone·iPad 앱에 적용되며 별도의 브라우저 확장·웹 앱에는 적용되지 않습니다.

2. 기기에 보관되는 정보

관심 자산·선택 자산, 관찰 알림 조건과 발생 상태, 앱 설정 및 제한된 앱 동작 기록을 기기의 SQLite 저장소와 앱 설정 저장소에 보관합니다. 앱은 회원가입을 요구하지 않으며, 이 로컬 데이터베이스를 MyQuant 운영 서버에 업로드하는 기능은 없습니다. 기기 간 자동 동기화 기능도 없습니다. 기기의 백업·복원 설정에 따라 운영체제의 백업에 포함될 수 있습니다.

3. 시장 데이터 요청

사용자가 자산을 선택하거나 차트 구간을 바꾸면 앱은 Upbit, Binance, Yahoo Finance의 공개 시세·차트 서비스에 자산 심볼과 구간 등 조회 조건을 전송합니다. 이때 IP 주소 등 네트워크 연결에 필요한 정보는 제공처에 전달될 수 있으며 제공처의 정책이 적용됩니다. 문의 연락처, 거래소 계정 비밀번호, 로컬 알림 조건 또는 분석 질문을 시세 조회 요청에 포함하지 않습니다.

4. 클립보드·공유·외부 AI

사용자가 복사 버튼을 누르면 분석 질문을 시스템 클립보드에 저장합니다. 공유 버튼은 사용자가 선택한 수신 앱으로 iOS 공유 화면을 통해 내용을 전달할 수 있게 합니다. 선택한 AI 앱·공식 웹사이트를 여는 기능도 있으나, 질문의 붙여넣기와 전송은 사용자가 직접 합니다. MyQuant Lite가 질문을 자동 입력·전송하지 않습니다. 외부 서비스에서 사용자가 보내는 정보에는 해당 서비스의 개인정보 정책이 적용됩니다.

5. 알림과 권한

사용자가 관찰 조건을 추가하면 알림 권한을 요청할 수 있습니다. 앱에서 시장 데이터를 조회할 때 조건을 점검하고 권한이 허용된 경우 로컬 알림을 예약합니다. 상시 백그라운드 시세 감시 서비스가 아니며, 알림 권한은 iOS 설정에서 변경할 수 있습니다. 현재 앱은 연락처·사진·정밀 위치·광고 식별자 권한을 요청하지 않고 광고·추적 SDK를 포함하지 않습니다.

6. 고객지원 문의

사용자가 이메일로 문의하면 회신 주소와 문의 내용을 문의 확인·답변에 사용합니다. 필요한 앱 버전·기기·오류 상황만 보내 주세요. 비밀번호, API 키, 계좌·거래내역, 신분증 등 불필요한 민감정보는 보내지 마세요. 문의 정보의 처리나 삭제에 관한 요청도 위 연락처로 보낼 수 있습니다.

7. 웹사이트 접속

이 페이지는 GitHub Pages에서 제공됩니다. 별도의 분석·광고 스크립트나 입력 폼을 추가하지 않았습니다. 호스팅 제공자는 웹페이지 전달·보안 등을 위해 접속 정보를 처리할 수 있습니다. 자세한 사항은 GitHub 개인정보처리방침을 참고하세요.

8. 보관·삭제와 선택

사용자가 추가한 관심 자산과 알림 규칙은 앱의 관리 화면에서 삭제할 수 있습니다. 기본 관심 자산 목록은 삭제 대상이 아닙니다. 앱 로컬 데이터 전체를 제거하려면 운영체제의 앱 삭제 기능을 사용하세요. 앱 정리하기(오프로드)나 시스템 백업에는 데이터가 남을 수 있으므로 백업은 기기 설정에서 별도로 관리해야 합니다. 운영자는 사용자의 기기 안에만 저장된 데이터를 원격으로 조회·복원·삭제할 수 없습니다.

9. 변경과 문의

기능이나 정보 처리 방식이 달라지면 이 안내와 스토어 개인정보 설명을 갱신합니다. 변경일은 이 페이지에 표시합니다.
